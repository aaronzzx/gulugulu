
# gulugulu · 侧边手势

> 一划即达——在屏幕边缘轻轻一滑，唤起你最常用的操作。

gulugulu 是一款基于无障碍服务的侧边手势工具。它在屏幕边缘和底部放置可自定义的「手势触钮」，让你不必来回找图标、按按键，滑一下就能启动应用、控制系统、调音量亮度，把高频操作收进指尖。

## ✨ 核心特性

### 🎯 自由布置手势触钮
- **底部触钮 + 侧边触钮**两套体系，位置、大小、颜色、透明度随心调
- 想要几个加几个，左、右、底边都能放
- 触钮可隐藏，需要时再唤出，不挡视线

### 👆 一个触钮，多种手势
每个触钮都能识别多方向手势，一处映射多个动作：
- 上滑 / 下滑 / 平滑触发不同操作
- 单击、长滑各自独立配置
- 触发距离、震动反馈细致可调

### 🧰 海量动作，任意组合
- **系统按键**：返回、主页、最近任务、通知栏、快捷面板、电源菜单
- **音量与媒体**：音量加减、静音、播放/暂停、上一首/下一首
- **屏幕操作**：锁屏、截屏、智能截图、录屏、单手下拉、屏幕常亮、快速回顶/到底
- **应用相关**：启动应用、小窗启动、启动快捷方式、上一个应用、关闭当前应用、分屏、应用小窗
- **效率工具**：任务切换器、精准点击、手电筒、语音助手
- **扫码支付**：微信/支付宝 扫一扫、付款码 一步直达
- **进阶玩法**：Shizuku 执行 Shell 命令、快速启动器

### ⚡ 快速工具面板
一次手势唤出常用开关：**音乐控制、音量、亮度、静音**随手就调，**Wi‑Fi、蓝牙、手电筒、通知面板、快捷设置、锁屏、截屏**也一并收纳，无需层层进系统设置。

### 🎨 精致动画与面板样式
- 触发动画：**波浪 / 胶囊 / 圆泡** 三种风格
- 动作面板：**扇形 / 文件夹** 两种排布，多动作一目了然

### 🔧 贴心细节
- 应用黑名单：指定 App 内自动让位，不误触
- 配置备份与恢复，换机迁移无忧
- 应用内检查更新，及时获取新功能

## 🚀 开始使用
1. 下载并安装最新 APK
2. 开启**无障碍服务**，授予手势监听权限
3. （建议）允许**忽略电池优化**与**自启动**，保证后台稳定
4. 在「手势触钮」里添加并自定义你的第一个触钮
5. 为每个手势绑定动作，开滑！
